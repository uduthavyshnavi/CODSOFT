CodSoft Machine Learning Internship Projects

This repository contains my task submissions for the CodSoft Machine Learning Internship.

Spam SMS Detection (Task 4)
Overview: Built an NLP text classifier to categorize messages as spam or ham (legitimate).
Steps: Applied TF-IDF vectorization on text data and compared Naive Bayes, Logistic Regression, and Support Vector Machines.
Evaluation: Checked performance using accuracy, precision, recall, and F1-score.

Customer Churn Prediction (Task 3)
Overview: Built a model to predict whether a customer will leave a subscription service.
Steps: Preprocessed customer data, handled missing values, encoded categorical features, and trained Logistic Regression, Random Forest, and Gradient Boosting models.
Key Outcome: Extracted feature importances to identify key factors influencing churn.

Credit Card Fraud Detection (Task 2)
Overview: Trained ML algorithms to identify fraudulent credit card transactions.
Steps: Preprocessed imbalanced transaction data, scaled amount features, and used class weighting with Logistic Regression, Decision Trees, and Random Forests.
Evaluation: Evaluated model effectiveness using Precision, Recall, F1-Score, and ROC-AUC.
